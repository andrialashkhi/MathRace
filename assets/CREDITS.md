# Logo — derived from Twemoji (CC BY 4.0)

`logo.svg` (used as the favicon and the landing-page hero mark) is a recolored,
recomposed derivative of the "chequered flag" emoji graphic from **Twemoji**
(originally by Twitter, Inc., now maintained at github.com/jdecked/twemoji),
licensed **CC BY 4.0** — https://creativecommons.org/licenses/by/4.0/.

The flag's pole/checker path geometry is Twemoji's; everything else (the
rounded violet badge, the recolored checker fill, the speed-line accents) was
added on top to match this site's palette. Because CC BY requires attribution
(unlike the CC0 character/font assets elsewhere in this repo), this file is
the attribution record for it.
